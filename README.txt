MoneyMate — Daily Money Manager (first prototype)

Included:
- English/Bangla interface toggle
- Quick income and expense entry
- BDT currency
- Daily, monthly and yearly reports
- Category totals
- Local device storage in browser
- Export/import JSON backup

Important:
- This is a working browser prototype, not yet a signed Android APK.
- Online account login and cloud synchronization are NOT implemented yet. The current version stores records locally in the browser on the device.
- For safety, export a backup regularly.
- Do not treat this prototype as your only financial record.

How to try:
1. Open index.html in Chrome on your phone or computer.
2. Add a transaction and visit Reports.
3. Use Settings > Export backup to save your data.
4. For an installable Android app with reliable local storage and cloud sync, the next step is to package the interface and connect a secure backend (for example, Firebase or Supabase).
